# Portfolio design system

Intent: посетитель изучает реальные проекты автора, открывает подробности и исходники. Интерфейс должен ощущаться как авторский каталог работ, с акцентом на сами проекты.

Domain: коллекция, карточка каталога, рабочий прототип, исходный код, окно приложения, выпуск, архив.

Color world: бумага, типографская краска, светлый картон, синий штамп, тёмный экран, белые контуры.

Signature: единая нумерация 01—15 проходит через каталог, карточки и страницы проектов. На первом экране — типографический указатель Web / Apps / Play с переходами в категории и отдельной ссылкой на расширения.

Choices: вместо экрана терминала — светлый редакционный каталог; вместо процентов навыков — проверяемый стек проектов; вместо выдуманных кейсов — настоящие описания, материалы и статус архива.

Palette: paper #f5f4ef; ink #24271f; secondary ink #5b5e54; cobalt #2947df. Цветовой акцент отмечает действия; индивидуальные фоны обложек помогают различать работы.

Depth: surface shifts. Плоские обложки, тонкие разделители, без декоративных теней. Типографическая панель первого экрана использует сплошной кобальтовый фон, крупные названия направлений и тонкие разделители.

Surfaces: base paper, raised #eeede7, inset #e6e5de. Тёплая основа объединяет скриншоты разных приложений.

Typography: Segoe UI с системными запасными шрифтами для интерфейса; Georgia italic для редакционного акцента; Consolas для индексов и технических подписей. Никаких внешних запросов к шрифтам.

Spacing: база 4 px; 8, 12, 16, 24, 32, 48, 64, 96 px. Поля clamp(20px,4.5vw,80px). Две колонки проектов на больших экранах и одна на телефоне. Радиус обложек 8 px, кнопок 3 px.

Accessibility: семантические заголовки; skip link; кнопки с aria-pressed; статус поиска aria-live; dialog с Escape и возвратом фокуса; reduced motion; видимые focus rings; статический каталог доступен без JS.
