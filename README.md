# adock — портфолио

Статический сайт с каталогом 15 проектов: 14 публичных репозиториев reallynigeuteg7-ux и RouteHub, добавленного по запросу владельца по состоянию на 5 ноября 2026 года. Описания основаны на README проектов. Изображения взяты из репозиториев и реальных снимков приложений. MINIMA показана в демо-режиме, QuietFrame — в версии 0.2, Facade Documents — с новым пустым заказом без подключения к CRM. Исходный код приватных проектов не публикуется; у RouteHub показаны описание и скриншот экрана входа. Вымышленных клиентов, отзывов и результатов нет.

## Запуск

Нужен Node.js 22+. Сторонних зависимостей нет.

```sh
npm run build
npm start
```

Локальный адрес: http://127.0.0.1:4173

## Где редактировать

- `data/projects.json` — проекты: названия, тексты, категории, технологии, галереи и внешние ссылки.
- `scripts/build.mjs` — шаблоны главной, страниц проектов и 404. Здесь же имя автора и контакт GitHub.
- `public/style.css` — оформление и мобильные стили.
- `public/app.js` — фильтры, поиск, параметры URL и увеличение изображений.
- `public/assets/sources.json` — источники изображений.
- `.interface-design/system.md` — принятые решения дизайна.

После правок выполните `npm run build`. Каталог обновляется из JSON при сборке; автоматической синхронизации с GitHub нет. Количество проектов в шаблонах, фильтрах и поиске рассчитывается автоматически.

## Vercel

В `vercel.json` заданы команда сборки `npm run build`, выходная папка `dist` и чистые URL. Для повторного деплоя в связанном проекте:

```sh
vercel deploy --project adock-portfolio --prod
```

Можно также импортировать исходники как Git-репозиторий с пресетом Other. Секреты, API-ключи и переменные окружения не нужны.
